11º TORNEIO REAL MANIMBU — VERSÃO VERCEL (SEM PHP)

TECNOLOGIAS
- HTML/CSS/JavaScript no site público
- Node.js nas Vercel Functions (API)
- Supabase PostgreSQL para persistência compartilhada

IMPORTANTE: A Vercel não grava alterações permanentes em arquivos JSON do projeto. O Supabase é necessário para que os resultados salvos pelo administrador sejam vistos por todos os visitantes e continuem salvos após novos deploys.

PASSO 1 — CRIAR O BANCO SUPABASE
1. Acesse https://supabase.com e crie uma conta/projeto.
2. No projeto, abra SQL Editor > New query.
3. Copie todo o conteúdo de supabase.sql, cole e clique em Run.
4. Vá a Project Settings > API (ou Data API / API Keys, conforme a interface).
5. Copie Project URL e a chave service_role/secret. A chave secreta fica somente nas variáveis da Vercel; nunca a coloque no HTML nem publique em repositório.

PASSO 2 — SUBIR PARA O GITHUB
1. Extraia o ZIP.
2. Envie todos os arquivos e pastas para a raiz do repositório GitHub.
3. Faça commit e push.

PASSO 3 — PUBLICAR NA VERCEL
1. Acesse https://vercel.com e importe o repositório GitHub.
2. Framework Preset: Other. Root Directory: ./ (raiz do projeto).
3. Antes ou depois do primeiro deploy, abra Project > Settings > Environment Variables.
4. Cadastre estas variáveis para Production (e Preview se desejar):
   SUPABASE_URL = Project URL do Supabase
   SUPABASE_SERVICE_ROLE_KEY = chave secreta service_role/secret do Supabase
   ADMIN_USER = admin (ou outro usuário)
   ADMIN_PASSWORD = crie sua própria senha forte
   TOKEN_SECRET = uma string aleatória longa, com pelo menos 32 caracteres
5. Salve as variáveis e faça Redeploy para aplicá-las.

PASSO 4 — PRIMEIRO ACESSO
- Acesse o domínio publicado na Vercel.
- A página pública não exige login.
- Clique em Área do administrador e use ADMIN_USER e ADMIN_PASSWORD configurados na Vercel.
- Os dados iniciais das categorias e confrontos são carregados de data.json. Na primeira gravação do painel, os dados são persistidos na tabela do Supabase.

FUNCIONAMENTO
- Os resultados, times, fases, classificados, artilheiro e campeão podem ser editados no painel.
- A classificação para a fase seguinte é manual, sem exigir número par de equipes ou chaveamento matemático.
- A sessão administrativa expira após 8 horas.
- A chave service_role e ADMIN_PASSWORD nunca devem ser colocadas em arquivos públicos.

OBSERVAÇÃO
Este pacote não inclui credenciais do Supabase nem da Vercel. Você precisa criar o projeto Supabase e cadastrar as variáveis de ambiente para ativar o salvamento compartilhado. Não há senha padrão embutida no site.
